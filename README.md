# Beans & Pods - Analyse des ventes

## Description
Cette application Streamlit permet d’analyser les données de ventes de l’entreprise Beans & Pods afin d’identifier les tendances et proposer des recommandations marketing.

## Fonctionnalités
- Exploration des données
- Statistiques descriptives
- Analyse des ventes par produit, région et canal
- Analyse de corrélation
- Recommandations marketing

## Technologies utilisées
- Python
- Streamlit
- Pandas
- Matplotlib
- Seaborn

## Lancer l'application

1. Installer les dépendances :
pip install -r requirements.txt

2. Lancer l'application :
streamlit run BeansAndPod.py
